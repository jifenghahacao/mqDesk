# ADR 001：项目架构决策

- 状态：Accepted
- 日期：2026-07-26

## 背景

MQDesk 是面向小白用户的 RabbitMQ 桌面可视化管控工具，采用 Tauri 2.x 构建桌面壳，Preact 构建前端，Rust 核心库存放业务逻辑。

## 决策

1. 桌面壳由 Tauri 2.x 提供，入口为 `src-tauri/src/main.rs` -> `src-tauri/src/lib.rs`，负责窗口、托盘、权限和 Tauri 命令注册。
2. 业务逻辑集中在 `src-tauri/crates/core/`（crate 名 `mqdesk-core`），该 crate 不依赖 Tauri，可独立测试与复用。
3. `src-tauri/src/commands/` 仅作为命令路由层，负责请求解析、状态装配和错误转发，不写业务规则。
4. 前端代码位于 `src/`，使用 Preact + Vite，所有 RabbitMQ 操作经 `src/lib/api.js` 调用 Tauri invoke。
5. 本地存储使用 sled，密码加密由 `mqdesk-core` 的 `crypto.rs` 实现，凭据不出 Rust 进程。
6. `legacy/` 目录为旧 Go/React 项目归档，冻结不再修改。

## 后果

- 壳层、核心逻辑、前端三层边界清晰，便于独立测试和后续替换前端或壳层。
- 违反分层（如在命令层写业务规则、前端直接引入网络/AMQP 库）会破坏可维护性与安全模型。
