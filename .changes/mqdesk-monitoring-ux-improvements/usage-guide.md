# MQDesk 监控与可视化优化使用说明

## 一、多 MQ 连接状态显示

### 功能说明
在「连接」页保存多个 RabbitMQ 连接后，每个连接卡片会实时显示：

- **当前活跃**：绿色圆点，表示该连接是当前正在使用的连接。
- **在线**：绿色圆点，表示 Management API 可达，但当前未选中。
- **离线**：红色圆点，表示 Management API 不可达或认证失败。
- **检测中…**：首次加载时的过渡状态。

### 操作步骤
1. 打开左侧导航「连接」。
2. 点击「+ 新建连接」填写连接信息并保存。
3. 卡片每 5 秒自动刷新状态。
4. 点击卡片上的「连接」按钮切换到该连接。

## 二、集群节点监控

### 功能说明
通过单个连接即可查看整个 RabbitMQ 集群的所有节点运行状态与资源占用：

- 节点名称、运行状态、节点类型（disc / ram）
- 运行时长
- 内存使用率与具体字节数
- 磁盘空闲率与具体字节数
- 文件描述符、Erlang 进程、Socket 使用量

### 操作步骤
1. 在「连接」页选择一个集群节点并点击「连接」。
2. 点击左侧导航「集群节点」。
3. 页面自动加载节点列表，每 10 秒刷新一次。
4. 点击右上角「刷新」可立即更新。

### 注意事项
- 如果 RabbitMQ 是单节点，列表中只会显示一个节点。
- 节点数据来自 Management API `/api/nodes`，需要用户具有监控读取权限。

## 三、消费者信息可视化

### 功能说明
在「消费者」页可查看当前 vhost 下所有在线消费者的：

- **消费者标签**：客户端库生成的 consumer_tag。
- **订阅队列**：该消费者订阅的队列名称。
- **客户端地址**：消费者所在主机的 IP 与端口。
- **连接时长**：从建立连接开始计算的在线时长。
- **消费速率**：该订阅队列的 deliver_get 速率（条/秒）。
- **Ack 模式**：手动确认或自动确认。
- **Prefetch**：消费者预取数量。

### 操作步骤
1. 在「连接」页选择一个 RabbitMQ 连接。
2. 点击左侧导航「消费者」。
3. 页面自动加载消费者列表，每 10 秒刷新一次。
4. 使用顶部搜索框按标签、队列或地址快速筛选。

### 注意事项
- 消费速率是队列级别的 deliver_get 速率，用于反映该队列整体消费吞吐。
- 连接时长依赖 `/api/connections` 接口，如果 Management 插件未返回连接建立时间，则显示为 "-"。

## 四、安装包与数据持久化

### Windows 安装
1. 运行 `apk/MQDesk_x.x.x_x64-setup.exe`。
2. 安装程序会检测并自动安装 WebView2 运行时（离线/内网环境已支持）。
3. 安装完成后即可启动。

### 数据持久化
- 连接配置、消息追踪记录保存在 `%APPDATA%\mqdesk`。
- 密码单独走系统 keyring 加密，不存明文。
- 卸载时安装程序会询问是否保留应用数据；默认保留，方便重新安装后恢复连接。
