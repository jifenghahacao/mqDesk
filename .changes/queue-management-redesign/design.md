# 队列管理页重构设计文档

## 一、信息架构

```
QueuesView（队列列表页）
├── 统计横幅：总队列数 / 正常 / 告警 / 危险 / 空闲
├── 筛选栏
│   ├── 搜索框（按名称模糊匹配）
│   ├── 类型筛选：全部 / classic / quorum / stream
│   ├── 状态筛选：全部 / 正常 / 告警 / 危险 / 空闲
│   └── vhost 下拉（默认当前连接 vhost）
├── 数据表格
│   └── 名称 | 类型 | vhost | 状态 | Ready | Unacked | Total | 消费者 | 流入速率 | 流出速率 | 操作
└── 新建队列按钮

QueueDetailDrawer（右侧抽屉，宽度 720px）
├── 头部：队列名 + 类型 pill + 状态 pill + 关闭
├── Tab 导航
│   ├── 概览
│   ├── 消息
│   ├── 告警
│   ├── 审计
│   └── 性能
└── 底部操作栏（编辑 / 暂停 / 删除）

QueueCreateModal / QueueEditModal
├── 基础参数：名称、vhost、类型、持久化、自动删除
├── 高级参数：最大长度、TTL、死信交换机/路由键、优先级、惰性队列
└── 提交 / 取消

MessageDetailModal
├── 消息元信息：ID、时间、大小、状态、exchange、routing_key
├── Payload：JSON 格式化 + 复制
├── Headers：JSON 格式化
└── 操作：重发 / 移动 / 删除
```

## 二、页面布局

### 2.1 列表页

- 沿用现有 `page-head` + `card` + `tbl` 风格。
- 表格行 hover 高亮，点击整行打开抽屉。
- 状态列使用 `StatusPill` 组件（ok/warn/danger/idle）。
- 操作列固定「查看 / 暂停 / 删除」三个按钮。
- 表格底部显示「共 N 个队列」和刷新按钮。

### 2.2 详情抽屉

- 从右侧滑入，覆盖在主内容区上方，宽度 720px。
- Tab 使用胶囊式分段器（沿用 `.seg`）。
- 每个 Tab 内部使用卡片分组信息。

### 2.3 弹窗

- 新建/编辑队列使用居中模态框，高度自适应，最大高度 80vh。
- 消息详情使用居中模态框，宽 600px。
- 删除确认使用 `ConfirmDialog`，提供「备份消息」选项。

## 三、核心交互

### 3.1 筛选与搜索

- 搜索框输入后 300ms 防抖触发。
- 筛选条件变化后立即刷新列表。
- 筛选状态 URL 不持久化（桌面端无地址栏）。

### 3.2 队列详情打开

- 点击行打开抽屉，同时高亮当前行。
- 抽屉内 Tab 切换不重新拉取整个详情，仅首次进入 Tab 时加载。
- 关闭抽屉后取消后台轮询。

### 3.3 消息操作

- **Peek**：通过管理 API `GET /api/queues/{vhost}/{name}/messages/get` 获取消息，不消费。
- **重发**：读取 payload/headers，调用现有 `publish_message` 重新发布。
- **移动**：弹窗选择目标队列 → 重新发布 → 成功后可选择是否删除原消息。
- **删除**：调用管理 API 删除单条消息（通过 delivery_tag），需二次确认。

### 3.4 删除队列

- 确认弹窗显示队列名、消息总量。
- 提供「导出最近 N 条消息到 JSON 文件」选项（默认导出 1000 条）。
- 确认后调用 `DELETE /api/queues/{vhost}/{name}`。

### 3.5 启停队列

- Classic 队列支持 `pause` / `resume`（通过管理 API）。
- Quorum / Stream 队列显示「该类型队列不支持暂停」提示。

## 四、视觉与样式

- 复用现有液态玻璃设计系统：`--glass`, `--hairline`, `--primary`, `--ok`, `--warn`, `--danger`。
- 表格、按钮、Pill、空状态、加载态沿用现有组件。
- 趋势图使用 SVG 自绘（不引入新图表库，保持包体小）。

## 五、错误与空状态

- 列表为空：展示「暂无队列」提示，提供新建入口。
- 筛选无结果：提示「没有符合条件的队列」。
- API 失败：顶部 `banner danger` 展示错误信息。
- 无管理权限：提示当前用户（默认单用户）无权限执行危险操作。
