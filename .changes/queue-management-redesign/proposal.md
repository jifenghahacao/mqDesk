# 队列管理页重构提案

## 背景

当前 MQDesk 已具备基础队列列表（`QueuesView`）和队列详情（`QueueDetailView`），但功能较薄：缺少多维筛选、消息管理、队列操作、告警、审计和性能分析能力。用户希望将其升级为功能完善的 MQ 队列管理中心。

## 目标

在桌面端单用户场景下，实现一个覆盖「看、管、查、警、审、诊」的队列管理页面，同时避免把 MQDesk 做成多租户服务端平台。

## 范围

**全部 7 项需求按桌面端改造后实现：**

1. 队列概览（列表 + 多维度筛选 + 状态可视化）
2. 队列详情（配置参数 + 速率趋势 + 上下游连接）
3. 消息管理（peek 列表 + JSON 详情 + 重发/删除/移动）
4. 队列操作（创建/编辑/删除/启停）
5. 监控告警（阈值 + 应用内通知 + 历史记录）
6. 权限管理 → 改造为「危险操作二次确认 + 本地审计日志」
7. 性能优化 → 改造为「诊断建议卡片」（不自动执行）

## 关键决策

- **消息移动**：读取原消息后重新发布到目标队列，默认删除原消息，提供「保留原消息」选项。
- **趋势图**：使用 RabbitMQ 管理 API 实时采样，不持久化历史时序数据。
- **告警通知**：应用内 Toast + 侧边栏红点 + 可选托盘气泡（替代邮件/短信）。
- **队列列表**：使用表格视图，便于大量队列时紧凑展示。
- **删除备份**：删除队列前可导出最近 N 条消息到 JSON 文件。
- **告警阈值**：全局默认阈值 + 队列级覆盖。
